# 第一个对照实验：图像阈值与误报／漏检

准备日期：2026-10-17。先检验一个具体问题：保持特征库和原始分数不变，只改变图像校准分位数，误报与漏检怎样变化？

## 你现在做什么

1. 先写下预期：在同一批固定分数上，提高判断阈值，误报不会增加，但漏检可能增加。
2. 双击本文件夹里的 **分析误报阈值.cmd**。这一步不训练模型，不需要重新运行“运行可信基线”。
3. 窗口会输出三行对照：正常校准分位数 95%、97.5%、99%，对应阈值、正常图误报张数及缺陷图漏检张数。
4. 在新生成的 `04实验结果/02阈值分析/thresholds_日期_时间` 里查看 `threshold_comparison.csv`、`score_distribution.png` 和 `analysis.json`，把结果告诉助手。

阈值数值全部从原来的 44 张正常校准图分数计算。开发集 45 张图仅用来观察不同规则的后果；70 张保留测试图不读取、不评价。三个候选规则是在看过误报后提出的，因此报告明确标注为开发探索。

## 什么保持不变

同一个模型、同一个 176 张正常图建成的特征库、同一份原始分数、同一个数据划分和像素阈值。原始实验文件不会被覆盖。程序核对来源身份，并核对原始 95% 规则能否复现 3 张误报、0 张漏检。

这一步只探索图像判断阈值，不会改变热力图、白色像素预测区域或 AUROC，也不会自动选中或应用任何新阈值。

## 你要回答的问题

- 哪个规则减少了误报？有没有同时漏掉缺陷？
- 校准集中分数最高的正常图是否影响了高分位数阈值？
- 如果开发集出现 0 误报／0 漏检，为什么还不能声称所有新图片都可靠？
- 为什么图像判断改正后，原来的像素预测白块还可能保留？

先根据实验判断阈值策略是否值得继续研究，再考虑特征库采样、正常变化覆盖和特征实现。对校准策略的分析与算法核心创新分别描述。
