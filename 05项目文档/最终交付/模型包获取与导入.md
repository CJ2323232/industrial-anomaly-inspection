# 固定模型包：获取、校验与导入

本入口解决把已有固定模型迁移到新源码目录的问题，不训练模型，也不建立新的正常特征库。工具仅依赖 Python 3.10+ 标准库，校验和导入阶段不会加载 PyTorch 或反序列化模型。

## 获取范围

当前没有经过许可确认的公开权重下载地址。需要向有权提供模型包的持有人获取，并确认你的用途符合骨干权重、MVTec 数据及相关产物的适用许可。项目代码的 MIT 许可不自动覆盖这些权重、特征库和数据。

如果暂时没有模型包，可以先运行[无模型快速开始](无模型快速开始.md)，它无需下载图片或模型。SHA 校验确认文件身份，不证明提供者有权授权，也不是签名认证。

## 支持哪些包

|包标识|演示版本|包含内容|
|---|---|---|
|r18-reference-v1|r18_reference|ResNet18 骨干状态与 1802×384 正常特征库|
|wrn50-reference-v1|wrn50_a、wrn50_c_experimental|WideResNet50-2 骨干状态与 1802×1536 正常特征库|

A、C 共享 WRN50 包，评分定义及各自阈值由 final_demo_profiles.json 固定。K=11、输入 256、sigma4 不因导入而改变。仅下载通用 ImageNet 预训练权重不能替代本项目模型包。

登记清单：[model_artifacts.json](../../02代码与配置/configs/delivery/model_artifacts.json)。同时固定 model.pt、config.json 的文件大小和 SHA256；包里的 SHA 声明不能替换源码内的可信清单。

## 新用户：检查和导入

在源码根目录执行；下方 python 应指向 Python 3.10+。Windows 也可使用 py -3.10。检查、导入不需要先安装检测依赖。

~~~powershell
python -B "02代码与配置/scripts/model_artifacts.py" list
python -B "02代码与配置/scripts/model_artifacts.py" check --profile r18_reference
python -B "02代码与配置/scripts/model_artifacts.py" import --bundle "收到的模型包目录"
python -B "02代码与配置/scripts/model_artifacts.py" check --profile r18_reference
~~~

模型包是一个目录，恰好包含：
~~~text
模型包目录/
  bundle.json
  model.pt
  config.json
~~~

不要手工修改清单来迁就不匹配的文件。ZIP 文件需要先自行解压到目录；工具不负责解压。

默认导入到当前源码根目录 .cache/model-artifacts/<包标识>/。同一合法包重复导入不会覆盖；缺文件、大小或 SHA 不匹配、未知包标识、额外文件、非法 manifest 都会被拒绝。已导入目录损坏时不会静默退回另一份模型。

有历史结果的原项目仍可从登记的历史目录加载；新源码目录通过上述导入，无需复制整个 04实验结果。

## 检测

按根 README 安装检测环境，然后执行：

~~~powershell
.venv/Scripts/python.exe -B "02代码与配置/scripts/delivery_runtime.py" --profile r18_reference --device cpu --image "自己的图片.png"
.venv/Scripts/python.exe -B "02代码与配置/scripts/delivery_runtime.py" --profile wrn50_c_experimental --device cpu --image "自己的图片.png"
~~~

GUI 也会自动读取默认导入位置。C 保持实验候选身份。若只导入 R18，检查全部版本会报告 WRN50 缺失，应使用 --profile 检查已取得的版本。

可选自定义存储：导入时 --store "目录"，检测时 --artifact-root "同一个目录"；检查时 --store "同一个目录"。GUI 使用默认存储位置。

## 现有模型持有人：导出

仅在你有权使用、转移这些文件的范围内操作；命令不会上传任何内容，也不授予分发许可。输出必须是不存在的新目录。

~~~powershell
python -B "02代码与配置/scripts/model_artifacts.py" export --profile r18_reference --output ".cache/private-model-bundles/r18-reference-v1"
python -B "02代码与配置/scripts/model_artifacts.py" export --profile wrn50_a --output ".cache/private-model-bundles/wrn50-reference-v1"
~~~

## 缺失和错误排查

|情况|处理|
|---|---|
|缺少 model.pt / config.json|工具列出查找位置；取得完整合法包再导入|
|缺少 bundle.json|向提供者取得按导出命令生成的完整目录|
|SHA 或大小不匹配|不要改可信清单；核对版本，重新取得完整文件|
|已导入目录损坏|保留诊断，用新的 --store 位置导入；工具不会自动覆盖|
|只有 ImageNet 权重|不含正常 Memory Bank，不能作为固定检测包|
|缺 torch/anomalib|按根 README 安装检测依赖；轻量检查仍可直接运行|
|检查通过但无法检测|先运行显式集成测试；SHA 就绪检查不等于推理测试|

检查成功返回 0；缺文件和校验失败返回 2。集成测试入口见[测试与验证](测试与验证.md)。

本轮已在同一台 Windows 机器的独立源码目录导入两个真实包，并完成 CPU 加载与开发样例推理；不是另一台机器或其他操作系统的验证。
