# 无模型快速开始

Python 3.10+，不需要GPU、图片、模型或pip依赖：

~~~powershell
python -B -S "02代码与配置/scripts/run_public_score_summary.py"
python -B -S "02代码与配置/scripts/run_tests.py" --suite basic
~~~

公开输入为 公开复核摘要/score_frequencies.json：按评分组、划分、标签和精确分数统计频次，不含图像标识、逐图预测或A/B/C配对关系。它仍保留精确分数，部分桶计数为1，不是隐私匿名化保证。

程序重算45开发图的TP/FP/FN/TN、Precision、Recall、F1、AUROC、AP，核对原有30项指标；44正常校准图只报告已有阈值下的超限计数。严格score > threshold，不重新选择阈值。相同分数按组计算AP；AUROC同分计0.5。

输出为04实验结果/29公开分数复核下新的summary.json与中文报告，只有汇总结果。A/B误报1/8、漏检0/37；C误报0/8、漏检0/37，AUROC/AP均约1。这是既有开发证据，不是新独立验证。

完整paired_scores、逐图错误、原图与热力图留本地。原run_saved_score_example.py保留作本地历史复核，它依赖本地完整记录，不是新的公开快速开始入口。
