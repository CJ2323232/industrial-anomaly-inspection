# 研究模型包使用

当前两个ZIP为本地已准备候选，**尚无公网下载地址**。面向非商业研究，先阅读[模型许可核查](模型发布许可核查.md)。这里不宣称商用授权。

1. 获取配套源码及合法取得的 r18-reference-v1.zip 或 wrn50-reference-v1.zip。
2. 安装前无需深度学习依赖；标准库校验外层ZIP及每个文件，再按模型登记清单复核内部SHA。
3. 安装依赖后可使用CPU，不需要原始MVTec图片或重新建库。

~~~powershell
python -B "02代码与配置/scripts/install_model_release.py" --profile r18_reference --archive "r18-reference-v1.zip"
python -B "02代码与配置/scripts/install_model_release.py" --profile wrn50_c_experimental --archive "wrn50-reference-v1.zip"
python -B "02代码与配置/scripts/model_artifacts.py" check
~~~

模型存入 .cache/model-artifacts；许可与模型卡保存在同一模型库的 _notices/<artifact_id>/ 下。安装器拒绝坏SHA、重复ZIP条目、未登记路径、不安全路径、修改后的内部模型和覆盖损坏许可文件。导入不更改模型、特征库、K或阈值。

按[环境安装](环境安装.md)完成依赖后：

~~~powershell
.venv/Scripts/python.exe -B "02代码与配置/scripts/delivery_runtime.py" --profile r18_reference --device cpu --image "自己的图片.png"
.venv/Scripts/python.exe -B "02代码与配置/scripts/delivery_runtime.py" --profile wrn50_c_experimental --device cpu --image "自己的图片.png"
.venv/Scripts/python.exe -B "02代码与配置/scripts/delivery_app.py"
~~~

R18默认；WRN50 A使用wrn50_a；C为wrn50_c_experimental，固定K=11且仍为实验候选。--input-dir用于批量。输出在04实验结果的新目录，现有文件不覆盖。

未来公开Release登记真实HTTPS地址及SHA后，--download才可使用。当前调用它会提示未发布，不会拼接虚假的下载链接。下载器的HTTP流程使用模拟HTTPS响应做过测试；公网下载需在发布后实测，不能把本地ZIP导入称为公网下载验证。

原三文件目录包仍使用[旧导入入口](模型包获取与导入.md)，不能把研究ZIP整个目录直接传给旧入口。
