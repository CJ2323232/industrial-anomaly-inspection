# 环境安装


已验证的现有环境为Windows / Python3.10.10 / RTX3060 Laptop 6GB / torch2.6.0+cu118 / torchvision0.21.0+cu118 / anomalib2.2.0。已在本机新建隔离venv完成独立安装、pip check、模型加载与CPU推理；未共享原环境已安装包。安装复用了项目pip缓存wheel。尚未验证另一台机器或不同操作系统。CPU推理入口可选，性能没有与GPU作等价承诺；Mac完整运行未经验证。

## 从公开源码重新建库与校准

这与“导入已登记研究模型后检测”是两条路径。下面是按公开源码核查的 **R18早期参考流程**，不是当前展示模型的逐位重制保证。本轮只执行输入预检，没有重新提取特征、选取Coreset或校准阈值。已有模型包的离线CPU检测成功，不能代替从全新下载数据开始的完整复现实测。

### 必要条件

- 使用本页Windows/Python3.10依赖；`run_trusted_baseline.py`明确要求anomalib 2.2.0和可用CUDA，当前没有CPU建库参数。已保存模型的推理可以选CPU。
- 从[MVTec AD官方页面](https://www.mvtec.com/research-teaching/datasets/mvtec-ad)按当前表单流程取得 **metal_nut原始文件与GT**。官方数据遵守CC BY-NC-SA 4.0，不能据源码MIT推定商用权利。解压后应存在 `03原始数据/解压数据/MVTecAD/metal_nut/train/good`、`test`、`ground_truth`；`--data-root`指向metal_nut的父目录。
- 使用仓库已有 `configs/splits/metal_nut-v1.json`，不要重建划分：176正常建库、44正常校准、45开发、70历史测试。预检核对前265张图片及37张开发GT的SHA，不读取70张历史测试图。
- R18骨干来自[timm/resnet18.a1_in1k](https://huggingface.co/timm/resnet18.a1_in1k)，需要 `model.safetensors`。参考文件SHA256为 `80c49dee3da4822c009c5a7fe591e9223c5a2cfcf95a4067ca4dfb5a7b89c612`。骨干预训练来自ImageNet；下载及使用条件与项目代码分别核查，详见[许可核查](模型发布许可核查.md)。
- 需要可用磁盘与RAM：建库、校准和原尺寸像素指标会保存连续分数并分配较大数组。已有6GB笔记本GPU运行记录，不代表任意6GB机器均保证成功。

### 1. 在项目根目录设置缓存并获取骨干

以下PowerShell命令供使用者复现；本轮未重新下载。不要在原有实验目录执行覆盖写入。

~~~powershell
$env:HF_HOME = Join-Path (Get-Location) '.cache/models/huggingface'
$env:TORCH_HOME = Join-Path (Get-Location) '.cache/models/torch'
$env:MPLCONFIGDIR = Join-Path (Get-Location) '.cache/matplotlib'
$env:HF_HUB_OFFLINE = '0'
.venv/Scripts/python.exe -c "from huggingface_hub import hf_hub_download; from pathlib import Path; import hashlib; p=hf_hub_download('timm/resnet18.a1_in1k','model.safetensors'); actual=hashlib.sha256(Path(p).read_bytes()).hexdigest(); assert actual=='80c49dee3da4822c009c5a7fe591e9223c5a2cfcf95a4067ca4dfb5a7b89c612', 'Upstream weight changed; stop and review'; print(actual)"
$env:HF_HUB_OFFLINE = '1'
~~~

下载命令使用上游main缓存，随后核对参考SHA；如果上游内容变化，停止复现并记录差异，不移除校验。该步骤不是下载本项目的Memory Bank。

### 2. 只检查输入，再按需建立新参考库

~~~powershell
.venv/Scripts/python.exe -B "02代码与配置/scripts/run_trusted_baseline.py" --check-only --data-root "03原始数据/解压数据/MVTecAD"
~~~

只有预检通过后，使用者才可自行执行以下建库命令。本轮没有执行：

~~~powershell
$newRun = '04实验结果/reproduction_' + (Get-Date -Format 'yyyyMMdd_HHmmss_ffff')
.venv/Scripts/python.exe -B "02代码与配置/scripts/run_trusted_baseline.py" --data-root "03原始数据/解压数据/MVTecAD" --seed 0 --batch-size 4 --coreset-ratio 0.01 --output $newRun
~~~

脚本的 `run` 会依次完成：正常图特征提取与1% Coreset建库、44张正常图校准、45张开发图推理及原尺寸评价、保存与重新加载检查。骨干保持冻结，不做梯度训练；建库仍是一次新的拟合运行。输出包括 `model.pt`、`config.json`、`calibration.json`、`development_predictions.csv`、连续图、可视化和 `report.json`。

**重要差别：** 此脚本的图像阈值是44个正常图像分数的95%分位数，像素阈值是这些图原尺寸像素分数汇总后的99.5%分位数，均采用linear插值、严格大于判异常。当前默认演示R18图像阈值来自后续97.5%规则，不能将这次新输出直接称为当前演示版本，也不能沿用旧指标。

### 3. 读取自己新建的checkpoint进行单图推理

标准演示入口只接受登记SHA的模型，**不会自动接纳新建库输出**。不应为绕过这一点修改冻结profile或模型目录。需要检验自己新建的早期参考模型时，可以在上述同一终端使用底层公开函数（只加载你自己生成或信任的checkpoint）：

~~~powershell
@'
from pathlib import Path
import json, sys
import numpy as np
sys.path.insert(0, str(Path("02代码与配置/scripts").resolve()))
from inspection_runtime import InputGuard, visualizations
from run_trusted_baseline import load_checkpoint, make_transform, predict
run = Path(sys.argv[1])
image, identity = InputGuard().load(sys.argv[2])
model, saved = load_checkpoint(run / "model.pt", "cpu")
model.requires_grad_(False)
score, amap = predict(model, make_transform(saved["model_config"])(image), (image.height, image.width))
tau = saved["thresholds"]
out = run / "single_image_check"
out.mkdir(exist_ok=False)
heat, overlay, mask = visualizations(image, amap, tau["pixel_threshold"])
for name, im in [("original", image), ("heatmap", heat), ("overlay", overlay), ("mask", mask)]:
    im.save(out / (name + ".png"))
np.savez_compressed(out / "scores.npz", anomaly_map=amap)
(out / "result.json").write_text(json.dumps(dict(score=score, thresholds=tau,
    anomalous=score > tau["image_threshold"], input=identity), ensure_ascii=False, indent=2), encoding="utf-8")
'@ | .venv/Scripts/python.exe -B - $newRun "03原始数据/解压数据/MVTecAD/metal_nut/test/scratch/021.png"
~~~

该例使用已知开发图；不开放历史70图，不生成新的独立验证成绩。snippet本轮仅做语法检查，未运行新模型推理；同名输出目录存在会拒绝覆盖。
