# 测试分层与复现范围

从源码根目录运行。所有临时测试文件放在当前项目 .cache/test-tmp；统一测试入口强制使用 CPU，不自动启用 CUDA 或真实模型测试。

## 1. 标准库基础测试：不需要任何检测依赖、模型或图片

~~~powershell
python -B -S "02代码与配置/scripts/run_tests.py" --suite basic
~~~

22 项测试覆盖模型包工具、非法 manifest、坏 SHA、缺文件、不可覆盖导入、ZIP安全解包、许可保留、下载校验、指标计算和公开摘要复核。夹具里的 model.pt 只是短字节串，不是真实模型，也不会反序列化。

## 2. 完整 CPU 单元测试：需要数值/检测依赖，但不需要本地权重

按环境安装文档安装 requirements-delivery.txt 与对应约束后：

~~~powershell
.venv/Scripts/python.exe -B "02代码与配置/scripts/run_tests.py" --suite unit
~~~

DeliveryInspector 构造使用依赖注入，模拟模型路径和配置；不再要求贡献者拥有登记权重。需要 CUDA 的旧测试会明确跳过，真实模型集成测试默认跳过。跳过不算验证通过。

当前完整CPU套件110项：限制OMP_NUM_THREADS=1、MKL_NUM_THREADS=1后，100项执行通过、10项明确跳过（9项CUDA、1项真实模型），0失败/错误。首次默认线程运行在最近邻数值测试处发生Windows原生访问冲突，退出码3221225477，没有完整测试结果；保留失败日志，不能宣称根因已解决。此前101项历史记录不覆盖。

复核命令可在上方命令前设置PowerShell环境变量：
~~~powershell
$env:OMP_NUM_THREADS='1'
$env:MKL_NUM_THREADS='1'
~~~

## 3. 真实模型集成测试：显式启用

先按照[模型包获取与导入](模型包获取与导入.md)导入合法模型。需要 R18 与 WRN50 两个包：

~~~powershell
.venv/Scripts/python.exe -B "02代码与配置/scripts/run_tests.py" --suite integration
~~~

可用 --artifact-root 指定模型库目录。一个集成测试内依次加载 R18、WRN50 A、WRN50 C 三个版本，校验模型与 Memory Bank 形状。没有图片输入，不进行训练；显式启用后缺模型会失败，不会伪装通过。

如需实际单图推理，执行 delivery_runtime.py --image，输出包含原图、热力图、掩码、分数和报告。不要为工程验收重新运行历史测试集。本轮只使用已登记开发图 good/005 做导入后封装检查，不新增性能成绩。

## 日志和边界

所有测试入口支持 --json "04实验结果/新的检查目录/结果.json"，记录失败、错误和每项跳过原因。终端输出保留具体测试名。

同机独立源码目录 + 已独立安装的隔离环境验证，不能等同于全新机器、全新网络下载或 Linux/macOS 兼容性保证。轻量基础入口和分数例子确已用 -S 禁用第三方包运行；完整单元与模型加载仍需 README 中的依赖。

## GitHub Actions基础CI

`.github/workflows/basic-tests.yml`仅运行本页的 `--suite basic`，使用Python3.10、`-B -S`，不执行pip安装、不加载权重、不读取数据集、不运行unit/integration或GUI。设置只读contents权限、10分钟超时，在Ubuntu和Windows runner上运行；官方checkout/setup-python按核查到的提交SHA固定。

远端结果以[对应提交的运行记录](https://github.com/CJ2323232/industrial-anomaly-inspection/actions/workflows/basic-tests.yml)为准。本地通过不等于远端通过；两个runner通过也仅证明标准库子集的跨平台运行，不代表CUDA、模型推理或GUI跨平台验收。完整CPU数值单元测试当前需要手动执行，未纳入此CI；没有公布代码覆盖率测量，不能把已执行用例占比当作覆盖率。设计参考[GitHub Python工作流文档](https://docs.github.com/en/actions/tutorials/build-and-test-code/python)。

## 格式检查边界

`code-quality.yml`只安装Black并运行格式检查。[pyproject.toml](../../pyproject.toml)登记5个脚本：delivery_runtime.py、delivery_topk.py、nearest_neighbors.py、resolution_metrics.py、run_tests.py。当前没有Ruff、mypy或类型检查门禁。格式检查不验证数值逻辑、算法有效性或实验指标；这些需要分别查看单元测试、集成测试和实验记录，不能由CI绿灯代替。
