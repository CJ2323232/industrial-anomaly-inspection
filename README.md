# 工业视觉异常检测与定位


面向**目标产品缺陷样本稀缺**的离线检测项目：用正常图片建立 PatchCore 特征库，对新图片输出异常判断、热力图、缺陷掩码和检测报告。提供 MVTec AD metal_nut 的既有实验分析、单图/批量推理、桌面界面和研究模型下载。当前定位为算法复现与离线检测原型，适用范围见下方实验和使用边界。

适合希望研究**评分机制、阈值选择、定位质量与推理成本**的计算机视觉学习者和研究者。默认采用 R18；WRN50 A 提供定位/召回取舍，Top-K（K=11）提供实验候选入口。

## 一分钟重算公开摘要：不用 GPU、模型或图片

只需 Python 3.10+，在源码根目录执行：

~~~powershell
python -B -S "02代码与配置/scripts/run_public_score_summary.py"
python -B -S "02代码与配置/scripts/run_tests.py" --suite basic
~~~

第一条从公开的**分数频次摘要**重算45张开发图的 A/B/C 图像指标，核对30项记录；第二条运行不依赖第三方包的22项基础测试。输出写入新的04实验结果目录。这两条命令不执行模型推理，也不重现70张历史测试或5880张跨域测试。

## 检测自己的图片

按[环境安装](05项目文档/最终交付/环境安装.md)配置依赖，阅读研究模型用途许可后：

~~~powershell
python -B "02代码与配置/scripts/install_model_release.py" --profile r18_reference --download
.venv/Scripts/python.exe -B "02代码与配置/scripts/delivery_runtime.py" --profile r18_reference --device cpu --image "你的图片.png"
~~~

批量输入使用 --input-dir；桌面GUI为 delivery_app.py，也可使用01运行入口中的“打开最终演示”。输出含原图、热力图、叠加图、掩码、连续分数、JSON与HTML。图像判断与像素掩码独立。

**研究模型已公开发布。** [下载 R18 / WRN50 模型包](https://github.com/CJ2323232/industrial-anomaly-inspection/releases/tag/research-models-v1)，也可使用上方 `--download` 自动下载、校验和导入。2026-11-04发布验收记录包含服务器端ZIP回下载及外层/内部SHA校验，以及本机既有隔离环境中的独立源码目录下载、导入和CPU检测。文件校验与推理入口验收不等于重现实验精度。完整步骤、各版本选择和许可证见[研究模型包使用](05项目文档/最终交付/研究模型包使用.md)。

## 技术结构

~~~mermaid
flowchart LR
  N[正常建库图] --> F[冻结骨干特征]
  F --> M[Coreset正常特征库]
  I[输入图片] --> P[统一预处理]
  P --> Q[多层Patch特征]
  Q --> D[最近邻距离]
  M --> D
  D --> S[邻居加权 / 最大距离 / Top-K]
  D --> H[上采样与平滑]
  S --> A[图像阈值判定]
  H --> B[像素阈值掩码]
~~~

PatchCore参考实现来自 anomalib；本项目贡献集中于数据与评价协议、评分及阈值诊断、质量/资源对照和工程封装。未宣称从零实现完整PatchCore、自建数据集或已经实现EfficientAD。
