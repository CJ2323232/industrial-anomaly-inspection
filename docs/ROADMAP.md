## 第一周逐日清单

1. 记录显卡、显存、系统内存、空闲磁盘与依赖；获取数据。
2. 检查 `metal_nut`，统计三个类别的正常／异常样本和缺陷类型。
3. 实现图片读取与 Dataset/DataLoader，核对张量尺寸及通道。
4. 加入掩码；正常图使用全零掩码；输出叠加图。
5. 固定数据划分清单，检查图片重复、路径交叉和标签。
6. 用少量图片检查 GPU 前向计算、保存加载与日志。
7. 写数据说明、问题清单和下一周计划。

## 核心实验

| 编号 | 起始配置建议 | 目的 |
|---|---|---|
| A0 | 整图 256 级别输入 | 基线 |
| A1 | 整图 512 级别输入 | 细节保留与成本 |
| A2 | 原图 256×256 分块，起始步长 192，重叠平均拼接 | 局部尺度检测与坐标还原 |

这些是项目实验配置，不是原论文参数。分块正常特征库与推理尺度匹配；记录边缘填充、有效区域、融合规则、图像评分和特征库实际容量。资源不足时分批执行，配置变化如实记录。

小面积异常按原图掩码并集占整图的比例预先分组，例如小于 0.1%、0.1%–1%、不小于 1%。报告每组数量；样本很少时以描述性案例为主。面积比例不等同于实际毫米尺寸。
