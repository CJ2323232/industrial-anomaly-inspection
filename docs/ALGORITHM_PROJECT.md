## 核心实现范围和正确性

PatchCore 的基本思路是用预训练网络提取正常图像的局部特征，保留有代表性的特征库，再用最近邻距离发现异常。[原论文](https://arxiv.org/abs/2106.08265)、[作者代码](https://github.com/amazon-science/patchcore-inspection)、[anomalib 参考实现](https://github.com/open-edge-platform/anomalib/tree/v2.2.0/src/anomalib/models/image/patchcore)。

保留 PyTorch 和预训练 ResNet18，核心学习实现不依赖 anomalib 的 PatchCore 类。预训练权重来源和许可继续记录。参考方法重实现与算法创新分别描述。

逐块实现和验证：

1. **冻结特征提取与多层融合**：记录归一化、局部池化、空间插值、特征展平顺序和张量尺寸。首先对齐同一骨干权重及相同预处理，不能把两套不同 ImageNet 权重的数值差异当作代码错误。
2. **特征库与子集选择**：先用小规模全量库验证距离；加入随机采样，再实现 k-center greedy。随机投影、初始化和随机种子是明确配置，记录与参考实现的差别。
3. **最近邻检索**：先以小张量全量距离为正确性基准，再按查询与库分块计算精确最近邻，比较距离与索引；出现等距离时比较最小距离及索引对应距离。分块旨在限制临时距离矩阵的内存，不能据此预先声称更快。
4. **评分和异常图**：先实现最大 patch 距离的简化图像评分，明确标记简化范围；再核对参考方法的邻域加权、插值和平滑。把异常图映射回原图再计算像素指标，正常分数不解释成概率。

通过条件是可复核的行为和差异说明。不同输入、预处理、子集或评分规则下的最终 AUROC 相近，不能证明两个实现等价。保留原始浮点分数，避免用阈值后的二值预测计算 AUROC。

## 重点实验：6GB 设备上的小缺陷检测

待检验的问题：降低输入分辨率可能丢失局部细节；提高分辨率或分块也可能增加特征数量、检索开销和纹理误报。实验需要判断这些现象在本数据和设备上是否出现，以及取舍是否值得。

| 对照 | 保持一致 | 观察 |
|---|---|---|
| 随机采样 vs k-center greedy | 相同正常拟合图、特征、特征库向量数、评分、校准规则 | 检测效果与建库成本，代表性子集是否值得 |
| 整图 256 vs 512 vs 分块 | 相同划分、骨干权重、特征层、预先设定的库容量和评价坐标 | 小面积缺陷检出、误报、运行时间与内存；单独记录候选特征数 |
| 特征库容量变化 | 固定输入方案和采样算法 | 效果与成本曲线；记录实际向量数、维度及字节数 |

阈值使用同一正常校准规则，每个配置单独由正常校准分数拟合数值。最终测试数据不用于选择阈值、库容量或分块步长。

先在 `metal_nut` 开发集完成有限配置的可行性检查，再冻结三类实验表。保留测试只执行预先冻结的配置。关键设置固定划分，使用 0、1、2 三个算法随机种子报告波动；不必给所有探索配置重复三遍。

小面积异常按原图标注面积比例分组，组界沿用评测协议；同时报告数量和缺陷类型。小样本组结果只能支持有限结论。分块、k-center greedy、分块检索均有已有技术基础，若要提出新算法，另行核对相关工作并验证新增机制。

## 每完成一块，个人需要留下的记录

| 记录 | 具体内容 |
|---|---|
| 原理 | 用自己的话解释输入、输出、关键公式和假设 |
| 代码 | 指出关键函数，解释张量尺寸，并实际改动一个参数或实现选择 |
| 预判 | 运行前写下预期变化及原因 |
| 验证 | 保存实际结果，解释与预期不同之处；记录失败，不挑选成绩 |
| 归属 | 分别记录论文方法、库功能、AI 协助和自己作出的判断、修改与验证 |

AI 辅助生成的代码不会自动成为个人独立实现经历。简历中的“实现”“设计”“优化”应对应本人能解释、修改和核验的工作。实验没有提升时，仍可诚实讨论排除的假设、发现的限制和最终取舍。

## 下一次的学习任务

从单张图的特征流开始。对输入 `[1, 3, 256, 256]`，核验 ResNet18 的 `layer2` 与 `layer3` 形状，再解释怎样融合成 patch 向量。预期形状分别为 `[1, 128, 32, 32]`、`[1, 256, 16, 16]`，融合展平后是 `[1024, 384]`；以实际前向结果为准。

需要自己讲清楚：为什么一张图会产生 1024 个 384 维向量；为什么不直接比较原始像素；正常训练图数与特征库向量数有什么区别；对 `N` 个查询和 `M` 个正常向量，一次性距离矩阵需要多少内存。

随后实现最近邻最小例子，手算几个向量距离，再扩展到 GPU 分块计算。学习笔记与代码对照记录将随实际完成情况添加。
