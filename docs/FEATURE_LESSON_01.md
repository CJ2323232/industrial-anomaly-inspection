## 先记录当前选择

暂定图像决策规则是独立正常校准分数的 **97.5% 分位数**（linear），严格大于阈值才判异常。当前模型对应完整数值 **13.575581574440001**；13.576 仅用于展示。换模型、特征库或预处理后，需要重新用正常校准分数求阈值。候选选择是开发结果，不是对未来准确率的保证。

## 现在做什么

1. 运行前写下你的预测：一张图片能产生多少个局部特征向量？每个向量有多少个数？
2. 在这台电脑双击本地提供的 `开始第一课_特征向量.cmd`。它使用现有模型中的冻结骨干，只读取固定拟合集中的第一张正常图片。
3. 等待 `FEATURE_FLOW_COMPLETED`。输出目录在当前代码仓库的 `artifacts/learning/feature_flow_时间/`，包含 `feature_flow.txt` 与可追溯的 `feature_flow.json`。若出现错误，保存终端原文，不把准备成功当作运行成功。
4. 对照下面的尺寸，逐行解释结果；尤其关注 `reference_max_abs_difference` 与比较是否通过。

其他电脑的运行方式：

```console
python scripts/inspect_feature_flow.py --baseline-dir PATH_TO_BASELINE --data-root PATH_TO_MVTecAD --check-only
python scripts/inspect_feature_flow.py --baseline-dir PATH_TO_BASELINE --data-root PATH_TO_MVTecAD --output-root artifacts/learning
```

只有输入检查时不执行前向；实际学习默认用 CUDA，也可添加 `--device cpu`。

## 要观察的变化

| 步骤 | 当前配置预期形状 | 含义 |
|---|---|---|
| 输入 | `[1, 3, 256, 256]` | 1 张、RGB 3 通道、256×256 |
| layer2 | `[1, 128, 32, 32]` | 32×32 个空间位置，每个位置 128 个特征数值 |
| layer3 | `[1, 256, 16, 16]` | 16×16 个空间位置，每个位置 256 个特征数值 |
| 局部平均池化 | 两层尺寸保持不变 | 汇聚邻近位置；边界填充的计算也需与参考一致 |
| layer3 对齐 | `[1, 256, 32, 32]` | 用双线性插值对齐空间网格 |
| 通道拼接 | `[1, 384, 32, 32]` | 同一位置组合 128+256 个特征数值 |
| 展平为局部向量 | `[1024, 384]` | 32×32=1024 个位置，每个向量 384 维 |
| 现有正常特征库 | `[1802, 384]` | 从多张正常图产生的候选特征里选出的 1802 个向量 |

空间位置对应重叠的网络感受野，不能把它说成独立切出的 8×8 原图小块。
