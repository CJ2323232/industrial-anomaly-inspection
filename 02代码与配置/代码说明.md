# 代码与配置

| 目录/文件 | 内容 |
|---|---|
| scripts/ | 算法、数据检查与实验脚本 |
| tests/ | 合成输入及数据流程的自动检查 |
| configs/splits/ | 固定的训练、校准、开发、保留测试划分 |
| configs/decisions/ | 暂定阈值决策 |
| requirements-first-run.txt | 依赖版本 |
| run_trusted_baseline_on_this_laptop.py | 本机基线环境与日志包装器 |
| run_on_this_laptop.py | 早期试跑包装器 |

普通使用从“01运行入口”双击启动。开发者在本目录执行测试，解释器使用上一级 `.venv/Scripts/python.exe`：

```powershell
..\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

数据和输出默认从脚本位置解析到项目目录，不依赖聊天窗口当前工作目录。
